🧹 Steam Dota 2 Guide Cleaner

I got tired of unsubscribing from 1000 Dota 2 guides manually after 20 years of playing. So I made a script.

A small userscript that clears old Dota 2 guide subscriptions without hours of pointless clicking.

Install scriptView on GitHub

What it does

🧹 Finds subscribed guides
⚡ Unsubscribes in batches
📊 Shows progress
🔄 Continues after reloads
🛑 Stops when the list is empty
⏱️ Adjustable speed

Safety first

The script does nothing until you press START CLEANUP and confirm. You can stop it at any time. Unsubscribed guides are not automatically restored, so use it only when you really want to clean your list.

Installation

Install Tampermonkey, install the userscript, open your Steam Dota 2 guide subscriptions, then press START CLEANUP.
